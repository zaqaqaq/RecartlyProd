# Recartly — дизайн-система «Смета» и правила разработки

Документ описывает продукт, визуальный язык и правила вёрстки. Любая правка UI должна ему соответствовать.

## 1. Идея продукта

Recartly — сообщество, где публикуют **рецепты** с ингредиентами, шагами, магазинами и стоимостью.
Главный сценарий отличается от «охоты за скидкой»: пользователь приходит с суммой на руках.

> «У меня 1000 ₽ на ужин в Казани на 4 порции — что можно приготовить и где это купить?»

Отсюда ядро продукта:

1. **Бюджетный подбор** — фильтр по сумме, городу, числу порций и категории.
2. **Смета покупок** — список продуктов с ценами конкретных магазинов города.
3. **Сплит-корзина** — честное сравнение «всё в одном магазине» против «разложить по нескольким»:
   показывает экономию в рублях и число магазинов.
4. **Балльные реакции и Индекс Recartly (RI)** — вместо «горячо/холодно».
5. **План питания** — «7 ужинов на 3000 ₽» с расчётом КБЖУ и ПП-режимами.
6. **Остатки дома** — подбор блюд, которые почти целиком собираются из того, что уже есть.

Ключевой принцип данных: **цена — это факт о магазине в городе на дату**, а не свойство рецепта.
Поэтому любой рецепт оценивается заново для конкретного города и числа порций.

## 2. Токены

### Цвета (`tailwind.config.js`)

| Токен | Назначение | Значение |
|---|---|---|
| `primary-500` | главный акцент, CTA, цена | `#0fa968` (изумруд) |
| `primary-600/700` | hover / pressed | `#0b8c56` / `#0a7046` |
| `hot-500/600` | ошибки, удаление, перебор бюджета | `#e5484d` / `#cc3b40` (коралл) |
| `secondary-400` | предупреждение, средние оценки, сезонность | `#f2a93b` (янтарь) |
| `cold-*` | нейтральные информационные акценты | голубой |
| `budget-ok / warn / over` | состояние бюджет-рейки | изумруд / янтарь / коралл |
| `ink-50…950` | кремовый фон, графит, тёмная тема «ночная кухня» | тёплые нейтральные |
| `shop-*` | фирменные цвета магазинов | — |

> ⚠️ Имя `primary` историческое: раньше это был зелёный, затем оранжевый Pepper, теперь — изумруд «Сметы».
> Использовать только токены: **никаких** `green-*`, `orange-*` напрямую.

### Типографика

- Заголовки: **Manrope** (`font-display`, класс `h1–h4` подключают автоматически).
- Текст и интерфейс: **Inter**.
- Все числа — `tabular-nums` (утилита `.tabular`): цены, ккал, граммы, суммы.
- Цены — только класс `.price` (+ `.price-lg`).

### Форма

- Карточки `rounded-2xl`, крупные блоки `rounded-3xl`, кнопки/инпуты `rounded-2xl`, чипы `rounded-full`.
- Тени: `.card` → `shadow-card`; чек → `shadow-receipt`.
- Easing: `ease-smeta`. Анимации: `animate-fade-in`, `animate-slide-up`, `animate-sheet-up`, `animate-rail`.

## 3. Компоненты «Сметы» (index.css)

- **Бюджет-рейка** — `.budget-rail`, `.budget-rail-fill` + `.budget-rail-fill-ok|warn|over`;
  компонент `components/BudgetRail.jsx` (состояния: в бюджете → близко к лимиту → перебор).
- **Чек-карточка** — `.receipt-card`, `.receipt-body`, `.receipt-tear`, `.receipt-notch`,
  `.receipt-row`, `.receipt-row-lead` (точки-выноски как в чеке); компонент `components/ReceiptCard.jsx`.
- **Сплит-корзина** — `.split-option`, `.split-option-best`; компонент `components/SplitBasket.jsx`.
- **Полки бюджета** — `.shelf-head`, `.shelf-title`, `.shelf-range`.
- **Метрики** — `.metric`, `.metric-value`, `.metric-label` (₽/порция, ккал, белок).
- **Индекс Recartly** — `.ri-badge` + `.ri-high|mid|low`, `.ri-bar`, `.ri-bar-fill`;
  компонент `components/RiBadge.jsx`.
- **Бюджетные сигналы** — `.budget-pill` + `.budget-ok|warn|over`.
- **Список покупок** — `.check-row` (чекбокс + название + цена, тач-таргет ≥44 px).

Базовые: `.btn-primary|secondary|outline|danger|ghost`, `.card`, `.input`, `.chip`, `.tag`,
`.avatar`, `.skeleton`, `.tab-pill`, `.bottom-nav*`.
Утилиты: `.safe-top|bottom|x`, `.pb-bottom-nav`, `.hscroll`, `.no-scrollbar`, `.press`, `.tabular`, `.line-clamp-1..4`.

## 4. Правила мобильной вёрстки (обязательно)

1. **Mobile-first**: базовые классы — мобильные, дальше `sm:` / `md:` / `lg:`.
2. **Никакой горизонтальной прокрутки**; для широких лент — `.hscroll` (snap + скрытый скроллбар).
3. **Тач-таргеты ≥ 44×44 px**; иконочные кнопки — `w-10 h-10` + `flex items-center justify-center`.
4. **Таблицы** превращать в карточки-строки, а не скроллить вбок.
5. Отступы: контейнер `px-3 sm:px-4 lg:px-6`, вертикаль `py-4 sm:py-6`.
6. Сетки: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`.
7. Модалки — bottom-sheet: `inset-x-0 bottom-0 rounded-t-3xl` + `animate-sheet-up`.
8. CTA — `sticky bottom-0` с фоном и `safe-bottom`, доступно большим пальцем.
9. Длинные заголовки — `line-clamp-2`, описания — `line-clamp-2/3`.
10. **Тёмная тема обязательна** для каждого нового элемента.
11. **Не ломать логику**: запросы `services/api.js`, хуки, роуты, тексты. Меняются разметка и классы.

## 5. Каркас приложения

- `Navbar` — липкая шапка: **кнопка «назад»** (ведёт по истории, а не на фиксированный раздел),
  логотип, поиск, **колокольчик уведомлений** со счётчиком, тема, меню профиля
  (со ссылками на витрину, ленту, меню, остатки, челленджи и пунктом «Модерация» для модераторов).
- `BottomNav` — нижняя навигация (только мобильные): **Витрина**, Лента, акцентная «+», Меню, Профиль;
  шторка «Что добавим?» включает рецепт, корзину, отзыв, остатки дома и меню на неделю.
- **Главная — витрина подбора** (`/`): бюджет, город, порции, число магазинов, фильтры
  (категория, время, сложность, КБЖУ, сортировка), полки бюджета, популярное по Индексу Recartly
  и блок «Цены в вашем городе». Лента сообщества живёт на `/feed`, `/budget` редиректит на `/`.
- `useSmartBack(fallback)` — «умный возврат»: `navigate(-1)`, если в истории есть предыдущий экран,
  иначе переход на `fallback` (для прямых заходов по ссылке).
- Контент получает `.pb-bottom-nav`.
- `Footer` — компактный, с оговоркой о партнёрских ссылках.

## 7. Backend «Сметы»

### Ключевые таблицы

`cities`, `shops`, `shop_cities`, `products` (КБЖУ, сезонность, фасовка `pack_size`/`pack_units`),
`price_quotes` (цена продукта в магазине города + история), `reactions` (вкус/выгода/просто + «приготовил»),
`cooked_photos`, `baskets` + `basket_items` (личная смета с чекбоксами и шарингом), `purchase_clicks`
(учёт партнёрских переходов), `meal_plans` + `meal_plan_items`, `pantry_items`,
`moderation_tasks`, `reports`, `audit_log`, `user_sanctions`, `challenges` + `challenge_entries`.

Расширены `recipes` (порции, время, сложность, категория, сезон, КБЖУ, RI, статус модерации)
и `users` (роль, доверие, город, санкции, баллы).

### Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/geo/cities`, `/geo/shops` | города (поиск `q`, 1085 городов) и магазины (в том числе по городу) |
| POST | `/geo/cities` | добавить город, которого нет в справочнике (название с большой буквы) |
| GET | `/catalog/budget` | подбор рецептов под бюджет и город |
| GET | `/catalog/shelves` | полки бюджета |
| GET | `/catalog/recipes/{id}/cost` | смета рецепта: single/split, ₽/порция, КБЖУ |
| GET | `/catalog/seasonal`, `/catalog/price-history/{id}` | сезонность и история цен |
| GET | `/catalog/trends` | «Цены в вашем городе»: подешевело / подорожало / в сезон |
| POST/GET | `/reports…` | жалобы на контент (публичный вход для очереди модерации) |
| GET/POST | `/notifications…` | уведомления: список, счётчик, отметка прочитанного |

| GET/POST | `/admin/…` | очередь модерации, жалобы, санкции, журнал, метрики |

| GET/POST/DELETE | `/pantry…` | остатки дома и подбор блюд с малой докупкой |
| GET/POST | `/admin/…` | очередь модерации, жалобы, санкции, журнал, метрики |

### Расчёт себестоимости

`services/pricing_service.py` — единственный источник правды:
сопоставление ингредиентов со справочником (по названию и алиасам), учёт фасовки
(«400 г макарон» = 1 упаковка, «4 шт» яиц = 0,4 упаковки), раскладка по магазинам
(жадный алгоритм с ограничением числа магазинов), КБЖУ и Индекс Recartly.

### Миграции и сиды

`backend/scripts/migrate_smeta.py` — идемпотентно создаёт таблицы, добавляет колонки,
заполняет города, магазины (с профилями цен по категориям), продукты с КБЖУ и цены.
`backend/scripts/seed_demo.py` — демо-рецепты. `check_db.py`, `smoke_pricing.py`, `smoke_mealplan.py` — диагностика.

```bash
.venv\Scripts\python.exe backend\scripts\migrate_smeta.py
.venv\Scripts\python.exe backend\scripts\seed_demo.py
```

## 8. Монетизация (заложено в коде)

1. **CPA-переходы** — `purchase_clicks` + `/go/{shop_id}`; шаблоны ссылок в `shops.affiliate_template`.
2. **Спонсорские подборки** магазинов — с обязательной пометкой «реклама».
3. **Премиум** — меню, история цен, семейные сметы (точки расширения готовы).
4. **B2B-аналитика** — данные о спросе по городам (таблицы цен и покупок уже собираются).

Нейтральность обязательна: партнёрская программа **не влияет** на цены, RI и порядок выдачи.
