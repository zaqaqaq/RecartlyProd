# Recartly — frontend

React 18 + React Router 6 + Tailwind CSS 3 (Create React App).
Приложение адаптировано под мобильные устройства и работает как **PWA**: его можно установить
на домашний экран Android/iOS и открывать без адресной строки, как обычное приложение.

Дизайн-система и правила вёрстки описаны в [`DESIGN.md`](./DESIGN.md).

## Концепция продукта

**Инструмент бюджета на еду.** Главный вопрос: «Сколько у меня денег и что я могу из этого
приготовить?» Полное описание — в [CONCEPT.md](../CONCEPT.md), ревизия функционала —
в [FEATURES_REVIEW.md](../FEATURES_REVIEW.md).

| Сущность | Что это | Живёт |
|---|---|---|
| **Блюдо** (рецепт) | Состав, шаги, фото, КБЖУ. Готовится из набора | Вечно |
| **Набор** | Продукты, магазины, цены, **дата покупки**, на сколько человек | Обновляется |
| **Продукт** | Справочник: название, КБЖУ-записи от авторов, алиасы | Растёт |

**Цена есть только у набора.** У блюда цены нет. Раздел определяется наличием набора: блюдо
без набора живёт в «Рецептах», блюдо с набором участвует в бюджетном подборе.

**Свежесть цен.** Дата покупки обязательна. Метки: ≤ 7 дней — «цены свежие», 8–30 — «цены от
12 сентября», > 30 — «цены устарели, обновите». Слово «актуально» не используется: дата честнее.
При обновлении цены старая зачёркивается («48 ₽» ~~55 ₽~~).

### Разделы

- `/` — главная: фильтр бюджета, «на сколько человек» (мультивыбор), сортировки, переключатель «Корзины | Блюда».
- `/basket/{id}` — карточка набора: состав, деньги, свежесть цен, «что из него приготовить», обсуждение.
- `/create-basket` — создание набора (дата покупки обязательна).
- `/recipes` — рецепты без набора.
- `/pp` — правильное питание: фильтры по калориям и белку.
- `/feed` — лента сообщества.
- `/promos` — акции от людей (после модерации).

## Быстрый старт (разработка)

```bash
npm install
npm start          # http://localhost:3000
```

Backend должен быть запущен на `http://localhost:8000` (см. `docker-compose.yml` в корне проекта).

## Production-сборка и PWA

Service worker регистрируется **только в production-сборке** — в режиме разработки он отключён,
чтобы не мешать hot-reload.

```bash
npm run build       # статика в ./build
npm run serve:build # локальный предпросмотр на http://localhost:5055 (SPA-fallback + PWA)
```

> Для проверки с телефона удобнее порт, разрешённый в CORS backend: `PORT=3000 npm run serve:build`.
> Backend разрешает запросы с `localhost`, `127.0.0.1` и локальных сетей (`192.168.*`, `10.*`, `172.16-31.*`).

Или через Docker (сборка + nginx, PWA активен):

```bash
docker compose -f docker-compose.prod.yml up --build
# приложение: http://localhost:3000
```

## Как установить приложение на телефон

1. Поднимите прод-сборку так, чтобы телефон был в той же сети, и откройте адрес по IP
   (например `http://192.168.1.10:3000`). Важно: PWA требует **HTTPS** либо **localhost**;
   для проверки по IP удобно поднять туннель (`ngrok http 3000`) или self-signed HTTPS.
2. **Android / Chrome:** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. **iOS / Safari:** «Поделиться» → «На экран “Домой”».

После установки приложение открывается в полноэкранном режиме (`display: standalone`),
получает оранжевую тему в статус-баре и офлайн-заглушку при отсутствии сети.

## Города

В справочнике **1085 городов России** (открытый датасет hflabs/city + Москва, Санкт-Петербург
и Севастополь, которых в датасете нет). Город выбирается выпадающим списком с поиском;
если города нет в списке, пользователь вводит его сам — название сохраняется с большой буквы
(«нижний тагил» → «Нижний Тагил»), повторный ввод возвращает уже созданный город.

Цены собраны пока для 8 городов. Если для выбранного города цен нет, витрина и смета считаются
по городу-эталону и честно помечаются флагом `prices_estimated` — «цены ориентировочные»,
чтобы человек не видел пустой экран и не принимал чужие цены за свои.

Обновить справочник городов:

```bash
.venv\Scripts\python.exe backend\scripts\build_cities.py   # CSV → JSON
.venv\Scripts\python.exe backend\scripts\migrate_smeta.py  # залить в базу
```

## Концепция «Смета» (главное в продукте)

Пользователь приходит с суммой: «у меня 1000 ₽ на ужин в Казани на 4 порции».
Сервис считает стоимость по ценам конкретных магазинов города и предлагает варианты закупки.

- **Витрина подбора** (`/`) — главный экран: бюджет, город, порции, число магазинов,
  фильтры (категория, время, сложность, КБЖУ, сортировка), полки бюджета,
  популярное по Индексу Recartly и блок **«Цены в вашем городе»**
  (что подешевело, что подорожало, что в сезон — на истории цен).
- **Лента сообщества** (`/feed`) — рецепты, корзины и отзывы от людей.
- **Смета покупок** (`/basket/:id`) — список продуктов с ценами магазинов, чекбоксы «куплено»,
  переключение стратегии **один магазин ↔ по магазинам** с показом экономии.
- **Семейная смета** (`/basket/shared/:token`) — ссылка, по которой близкие отмечают покупки.
- **Меню на неделю** (`/mealplan`) — план питания под бюджет с расчётом КБЖУ и ПП-режимами.
- **Остатки дома** (`/pantry`) — «собери из того, что есть»: показывает, что докупить.
- **Челленджи и награды** (`/challenges`) — «Ужин за 300 ₽», лидерборд, ачивки и баллы.
- **Уведомления** (`/notifications`) — комментарии, оценки, решения модерации, ачивки, счётчик в шапке.
- **Моя неделя** (`/week`) — что готовлю (активный план), что купил (сметы с отметками), траты,
  экономия на сплите и **сравнение с доставкой** («этот ужин против пиццы»).
- **Акции в вашем городе** (`/promos`) — люди делятся ценниками: товар, магазин, старая и новая
  цена, срок, фото. Публикуется **только после модерации**, поэтому фейковые «скидки» в ленту
  не попадают. Есть лайки и сортировки «горячие / свежие / максимальная скидка».
- **Цены от людей** — кнопка «📷 Указать цену из магазина» на странице рецепта и лента
  «свежие цены» на витрине: продукт, магазин, цена, фото ценника. Цена появляется в расчётах
  **только после подтверждения** (модератором или доверенным автором), за 5 подтверждённых
  цен выдаётся ачивка «Охотник за ценами».
- **Онбординг** — при первом входе 4 шага (город → бюджет → порции → карта разделов);
  при регистрации город обязателен.
- **Реакции** — вместо «горячо/холодно» три оси (вкусно / выгодно / просто) и **Индекс Recartly (RI)**;
  голос «я приготовил» весит вдвое больше.
- **Жалоба на контент** — кнопка «🚩 Пожаловаться» на рецепте, корзине и отзыве;
  жалобы попадают в очередь модерации.
- **Модерация** (`/admin`) — доступна ролям `moderator` и `admin`: очередь проверки, жалобы,
  санкции и журнал действий. Новые авторы (доверие < 60) и публикации с автофлагами
  (ссылки, телефоны, мат, спам, отсутствие фото) уходят на проверку и **не видны другим
  пользователям** до одобрения — ни в ленте, ни в поиске, ни по прямой ссылке.

Выдать роль модератора/администратора:

```bash
.venv\Scripts\python.exe backend\scripts\grant_admin.py user@example.com admin
```

Ключевые компоненты: `BudgetRail` (бюджет-рейка), `ReceiptCard` (чек-карточка), `SplitBasket`
(сравнение стратегий), `RiBadge` и `RatingWidget`, `PriceTrends` (цены города), `BudgetFilters`,
`ReportButton`, `NotificationBell`, `BackButton` + `useSmartBack`.

## Что уже сделано для мобильных

- **Нижняя таб-навигация** (`BottomNav`) — Лента, Поиск, акцентная кнопка «Добавить», Избранное, Профиль.
  Кнопка «Добавить» открывает bottom-sheet с выбором: рецепт / корзина / отзыв.
- **Адаптивная шапка** (`Navbar`) — на мобильных поиск отдельной строкой, меню — компактное.
- **Mobile-first вёрстка** всех страниц: одна колонка на телефоне, сетки с `sm:`/`lg:`.
- **Горизонтальные ленты** (`.hscroll`) с snap-скроллом для табов и фильтров.
- **Тач-таргеты ≥ 44 px**, отключены «серые вспышки» тапа, отключён авто-зум на iOS.
- **Safe-area** (`env(safe-area-inset-*)`) — контент не заезжает под «бровь» и системный бар.
- **PWA**: `public/manifest.json`, `public/sw.js`, офлайн-страница `public/offline.html`,
  иконки (в том числе maskable), `apple-touch-icon`, `theme-color`.
- **Тёмная тема** для всех новых элементов.

## Структура

```
public/
  manifest.json        манифест PWA
  sw.js                service worker (офлайн-оболочка, кэш статики)
  offline.html         офлайн-заглушка
  icons/               иконки PWA (192/512/maskable/apple-touch)

  services/api.js      клиент REST API
  utils/shopColors.js  фирменные бейджи магазинов

  serviceWorkerRegistration.js
```

## Чеклист проверки мобильной версии

- [ ] Нет горизонтальной прокрутки на 360 px.
- [ ] Нижняя навигация перекрывает контент только как оверлей, ничего не «прячет».
- [ ] Табы/фильтры скроллятся вбок со снапом.
- [ ] Формы: инпуты не вызывают зум на iOS, кнопки доступны большим пальцем.
- [ ] Тёмная тема: нет белых «пятен» и нечитаемого текста.
- [ ] Установка на домашний экран работает, приложение открывается в standalone-режиме.
